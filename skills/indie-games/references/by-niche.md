# Adapt by game type

These are recommended tests, not measured genre benchmarks.

| Type | What to show | What to check |
|---|---|---|
| Roguelike | A build changing the next decision | Viewers understand progression rather than only combat |
| Co-op | Friends creating a surprising shared failure | Scheduling, party setup and multiplayer stability |
| Cozy or simulation | A satisfying transformation and player control | Audience fit, input comfort and sustained session interest |
| Horror | Tension and a distinctive threat | Streamer response, spoiler boundaries and audio capture |
| Visual novel | Character conflict and meaningful choice | Language quality, readable footage and content expectations |
| Strategy | A decision and its consequence | UI legibility and tutorial abandonment |
| Adult | Accurate permitted store assets | Current platform and channel eligibility before promotion |
| Kids mobile | Actual play and age-appropriate creative | Owner-approved audience, store eligibility and retention cohorts |
| Tools or assets | Before/after inside the buyer's workflow | Compatibility and documentation; do not use game wishlist forecasts |

Use [store-page-trailer-demo](store-page-trailer-demo.md) for execution and [benchmarks](benchmarks.md) for evidence limits.
